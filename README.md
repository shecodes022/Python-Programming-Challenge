# About this Repository 📌

This repository contains my progress through the **30 Days of Python** challenge. Over 30 days, I worked through Python fundamentals and moved on to data analysis, web scraping, databases and APIs, with exercises for each day's topic.


# Key Takeaways 🔍

1. Python Fundamentals: Practised variables, operators, strings, data structures (lists, tuples, sets, dictionaries), conditionals, loops and functions.

2. Intermediate Concepts: Applied modules, list comprehensions, higher-order functions, exception handling, regular expressions, file handling and classes and objects.

3. Data & Statistics: Used Python's statistics tools and Pandas to analyse and manipulate data.

4. Web & Data Sources: Built web scrapers, worked with virtual environments and the package manager, and used MongoDB for storage.

5. APIs: Consumed external APIs and built my own, with Python web development in between.
